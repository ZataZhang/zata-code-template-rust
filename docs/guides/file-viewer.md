# 本机文件与改动查看器

`just view` 通过 Rust `tools/xtask` 在浏览器中打开当前仓库的查看器，默认显示 Git 改动。HTTP 服务只绑定 `127.0.0.1`，并限制文件读取在当前仓库内。

## 命令

| 命令 | 作用 |
|---|---|
| `just view` | 打开或复用查看器，进入改动视图 |
| `just view <路径>` | 打开后定位到仓库内的路径 |
| `just view --files` | 显示完整文件树 |
| `just view --diff` / `just diff` | 显示当前工作区改动 |
| `just view --stop` | 停止本仓库的查看器实例 |
| `just view --port <端口>` | 指定监听端口 |
| `just view --idle-timeout <秒>` | 设置空闲回收时间；`0` 表示不自动回收 |
| `just view --no-reuse` | 不复用已有实例，另起一个 |
| `just view --no-open` | 只打印访问 URL，不启动浏览器 |

运行需要 Git、浏览器和首次构建所需的 Rust 工具链；Cargo 会自动解析和构建 Rust 依赖，不需要 Python 环境或单独的 setup 命令。

查看器不提供编辑、提交、撤销暂存或丢弃改动功能。改动视图里的加号可以将单个文件或全部工作区改动暂存到 Git 索引；文件内容区也可以将路径交给系统默认应用打开。

## 界面

- 改动视图分为 `Staged Changes` 和 `Changes`。后者合并未暂存与未跟踪文件；点击文件可看逐行 diff，行号分列显示旧/新位置并以竖线分隔。未跟踪文件不显示增删统计。
- 文件视图显示仓库文件树，可筛选路径、展开目录和选择是否显示 Git 忽略项。依赖及缓存目录会隐藏。
- Markdown 文件默认显示渲染预览；位图文件显示图片，HTML 文件可在新标签页打开。其他文本文件显示语法高亮和行号；文件过大或为二进制时会给出说明。
- 页面不自动轮询。需要最新文件树或改动时，点顶部的刷新按钮；目录树只在打开或手动刷新时重新读取。

改动列表来自 Git 命令：已暂存比较 `HEAD` 与索引，未暂存比较索引与工作区，未跟踪文件单独读取。单文件改动详情按需获取。

## 安全与副作用

服务监听 `127.0.0.1`，文件路径解析后必须仍位于当前仓库内。HTTP 读取接口只读；有副作用的操作只有暂存到 Git 索引，以及把文件交给系统默认应用。暂存操作不会改写文件内容、提交或撤销已有暂存。写接口只接受小型 JSON 请求体。

Markdown 预览会执行文件中允许的原始 HTML。只在信任仓库内容时使用预览；不可信 Markdown 的脚本可能以本机查看器页面的来源运行。

## 实例与排障

查看器作为本机进程常驻；默认连续 30 分钟没有请求后自动退出。可以运行 `just view --stop` 手动停止。浏览器页面不发心跳，因此空闲页面可能在服务回收后失效；重新执行 `just view` 会启动或复用实例。

运行状态写入仓库根目录的 `.env.view-state`，服务日志在 `logs/view-viewer.log`。复用前会检查进程、端口和仓库根是否匹配。若页面显示服务已退出，或命令每次都重新启动，可先运行 `just view --stop` 再打开。
