# Code Reuse Guardrails

本页定义 AI 与开发者修改代码时必须遵守的防重复规则。目标不是一次性清理历史重复，而是让新增和修改代码优先复用、参数收敛、职责单点化。

## 复用优先

新增或修改功能前，先搜索现有实现：

- 用 `rg` 搜索 `crates/core/`（业务规则）、`crates/api/`、`crates/infrastructure/`、`crates/engines/`
- 业务规则优先复用 `tpl-core`；它是业务规则的唯一可信源，`tpl-api` 只做入口适配、参数校验、DTO 转换和用例调用
- 先看标准库和已有依赖是否已提供（`Option`/`Iterator` 的组合子、`itertools` 之类）再自己写

禁止复制粘贴已有代码后微调。发现逻辑重复率明显超过 50% 时，优先直接调用已有函数；调用方向不合适时，先提取公共规则或纯转换函数，再由调用方复用。

## 复用层次

| 类型 | 示例 | 规则 |
|---|---|---|
| 业务规则/校验 | `is_valid_port_code()`、`can_approve()` | 必须复用，集中管理 |
| 数据转换/映射 | `normalize_port_code()`、`to_response_dto()` | 应该复用，保持纯函数 |
| 数据查询/加载 | `load_all_ports()`、`fetch_user()` | 禁止被业务代码直接当规则复用 |
| 流程编排 | `run_recommendation_pipeline()` | 谨慎复用，优先复用其中的规则片段 |

具体要求：

- 判断「是否合法/有效/满足条件」的逻辑，提取为 `is_` / `can_` / `validate_` 开头的命名函数
- 业务代码不得直接调用「加载全量数据」的函数作为判断依据；规则函数内部决定缓存、预计算或加载方式
- 同一判断逻辑在当前变更中出现 2 次以上，即使只有两行，也提取为命名函数
- 安全相关的 `validate_` 判定要同时挂在**写入点**和**消费点**，两处调用同一个函数，不要为兜底另写一份；消费点命中时 fail-closed，且只跳过那一条
- 用户可写、最终交给第三方库或子进程的值，先确认该库会不会对它做变量展开或模板渲染，会就在上面两个点拒绝对应语法

## 参数收敛

- 函数参数超过 4 个时，收敛到结构体（可配 builder）或已有的上下文对象
- 3 个及以上参数总是一起出现时，提取为值对象
- 不透明实参（裸 `bool`、`None`、数字字面量）会让调用处难读：用具名的 `enum` 或配置结构体代替，如 `Mode::Strict` 而不是 `true`
- 用新类型区分含义不同的同类值（`UserId(i64)` 与 `OrderId(i64)`），避免参数顺序写反

```rust
// 推荐：具名字段，调用处自解释
let cost_values = fetch_costs(FetchCostsRequest {
    route_date_range: DateRange::new(start_date, end_date),
    partial_results: PartialResults::Allowed,
});

// 不推荐：不透明实参
let cost_values = fetch_costs("2026-01-01", "2026-01-31", true);
```

## 文件与模块

- 目标：单个 `.rs` 文件非空行少于 500 行；新增或重写文件不应超过 800 行；硬上限 1000 行
- 不创建只被引用一次的小 helper；只有当抽象减少真实复杂度、复用真实存在或匹配既有模式时才提取
- 不在同一文件里无限追加逻辑；接近 500 行时先判断是否需要新子模块
- 向 `tpl-core` 添加代码前，确认没有更合适的已有模块
- 两个模块出现重复，第一反应是抽象层级错了，而不是再写一份

## AI 编码自检清单

每次完成代码修改后，AI 必须在回复末尾显式回答：

- [ ] 我没有复制粘贴已有代码后微调（复用优先于复制）
- [ ] 我复用的是业务规则（`is_` / `can_` / `validate_`）而非数据加载操作
- [ ] 我的函数参数不超过 4 个，成组参数已收敛到结构体
- [ ] 我没有在同一文件里无限追加逻辑（当前文件非空行少于 800 行，目标少于 500 行）
- [ ] 我新增或修改的 `Cargo.toml` 依赖符合层间依赖方向
- [ ] 我的变量名解释了数据来源和状态（没有 `data` / `item` / `res` / `tmp`）
- [ ] 我运行了 `just lint`，且全绿
- [ ] 我同步更新了 `docs/`、`///` 与 `config.toml` / `.env.example`（如有影响）
- [ ] 我没有创建只被引用一次的小 helper 函数

任何未勾选项目必须在交付前修复，或在最终回复中说明原因与风险。
